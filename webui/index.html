Admin — edit upgrade chips per rebirth

Load a rebirth tier (Super Rebirth + Rebirth), view its current upgrade-chip total, edit it, and save straight to the database. Changes are read live everywhere (e.g. the stage-detail panel).

Admin — edit rebirth credit cost

Pick a rebirth level, change how many credits (and Nova) are required to perform that rebirth, and save straight to the config store. The new cost is read live everywhere — the stage-detail panel, the stat ETA, and any in-game enforcement — so the change takes effect immediately. (The credits shown are the required amount for that level, matching the rebirth_cost table.)
